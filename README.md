# Stichblock · Web-Testversion

Punkteblock für Wizard und andere Stichspiele, mit allen Versionen (Klassik, Jubiläum mit Bombe und Wolke, Junior, Extreme) und Varianten (Plus/Minus Eins, Verdeckter Tipp, Geheime Vorhersage, Hellsehen, Einfarbig, Maximus).

Öffne die Seite auf dem Handy und wähle „Zum Home-Bildschirm“ (iPhone) oder „App installieren“ (Android). Sie läuft danach auch offline. Spielstände bleiben nur auf dem eigenen Gerät.

Inoffizielle Fan-App ohne Verbindung zu Spieleverlagen.

- Wurzelverzeichnis: Web-App und Rechtstexte für GitHub Pages
- `appstore/`: Unterlagen und Screenshots für App Store Connect
- `app/`: Capacitor-Projekt für App Store und Play Store, Anleitung in `app/ANLEITUNG.md`
